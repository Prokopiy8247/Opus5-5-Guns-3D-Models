Версия: v10b Task2. Комплект от 16 октября 2026.

Открыть в Blender: **`models/Grenade_MkII_Studio_v10b_Task2.blend`**.

Принятая v10b с производственными фактурами и загрязнениями. Выбрана владельцем для этой публикации 16.10.2026. Более новая проверочная v11 в комплект не включена.

Проверено в Blender 5.2.2 LTS. Для просмотра материалов используйте Rendered / Cycles;
для редактирования нативных слоёв нужен UCUPaint 2.4.9.
Текстуры встроены в .blend. Внешние копии карт находятся в `textures/`,
их пути относительные. Чистые пустые заготовки масок UCUPaint сохраняют свои параметры генерации.
Шрифты, если они используются, встроены в .blend.

Существующие рендеры выбранной версии — `renders/`. Исходные сведения об источниках текстур — `credits/`.
Структурная проверка и соответствие карт — `validation.json`. Контрольные суммы — `SHA256SUMS.txt`.
