## Решения
- Окно выброса: у Mark XIX в положении «в боевом взводе» на правой стороне нет открытого окна — затвор (slide) закрывает болт; камора открывается только при отведённом затворе (фото Gunblast DSC03738, DSC03743). Механизм показываем рендером с отведённым затвором. [подтверждено фото]
- Safe mode аддона: геометрия bpy/bmesh-скриптами, рендеры фоновым Blender (`_tools\bg_render.py`), как у M1911.
- Bevel: clamp overlap выключен (иначе схлопывается по самому короткому ребру), под ним Weld против вырожденных граней.

## Неопределённости
- Высота: фото 155.9 мм против паспортных 158.75 мм; масштаб взят по длине (подтверждён прицельной линией).
- Внутренние размеры газовой системы (диаметры канала/стояка/цилиндра, длина поршня), шаг пружин — оценка по чертежам без масштаба (assumption).
- Форма дульного торца: на DSC03724 граница торец/скос подбородка — дуга, у модели — прямой излом (z −4); силуэт сбоку совпадает с k01.
- Тёмная «капля» перед носом рамки (k01, DSC03722) — выемка в подбородке не смоделирована (EXACT-булева по всему стволу ломала венец/уступ канала).
- Дульный торец (сравнение с DSC03724 в одном ракурсе): на фото лицевая часть торца — «надгробие» со скруглённым верхом (граница — дуга r ≈ 12 мм вокруг канала) и большим скосом справа-сверху; у модели торец выше и угловатее, конус короны по бокам даёт «талию». Силуэт сбоку при этом совпадает с k01 (±0.1 мм) — главное оставшееся расхождение формы.
- Скос задних углов затвора: сбоку полоса 6–7 мм, на k01 ≈3.2 мм (A13, геометрия).
- Вырезы казённого среза ствола под упоры — одинаковые (на фото 4 разных, A14); профиль насечек затвора (A16); общая ширина фасок (A11).
