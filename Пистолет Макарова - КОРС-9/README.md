# Пистолет Макарова / КОРС-9

> **Публичная версия.** Текстуры упакованы внутри `.blend`, поэтому отдельной папки `textures/` здесь нет. Все пути в файлах относительные, личных данных нет.
> Файлы больше 100 МБ не помещаются в репозиторий GitHub и лежат во вкладке Releases: `models/PM_Textures_100_v02.blend`, `models/PM_Textures_20_v04.blend`, `models/PM_Textures_60_v02.blend` — [скачать](https://github.com/Prokopiy8247/Opus5-5-Guns-3D-Models/releases/tag/models-v2). Положите их в папку `models/` рядом с остальными.

Версия: геометрия v11; 20% v04, 100/60% v02. Комплект от 16 октября 2026.

Открыть в Blender: **`models/PM_Textures_60_v02.blend`**.

Три состояния 100/60/20%. Сборки содержат коллиматор ЗОРИН К-1 и крепление. Отдельно приложены пустой и снаряжённый магазины v02, патрон и глушитель в состоянии 60%.

Проверено в Blender 5.2.2 LTS. Для просмотра материалов используйте Rendered / Cycles;
для редактирования нативных слоёв нужен UCUPaint 2.4.9.
Текстуры встроены в .blend. Внешние копии карт находятся в `textures/`,
их пути относительные. Чистые пустые заготовки масок UCUPaint сохраняют свои параметры генерации.
Шрифты, если они используются, встроены в .blend.

Существующие рендеры выбранной версии — `renders/`. Исходные сведения об источниках текстур — `credits/`.
Структурная проверка и соответствие карт — `validation.json`. Контрольные суммы — `SHA256SUMS.txt`.
